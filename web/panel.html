切号规则

    % 时提醒，并告诉你多久后重置

    时间规则在进入时间段时自动切换，时间段内你手动换号不会被改回去。目录规则在终端里用 cam claude 代替 claude 启动时生效。

    Claude 服务检测

    检查 DNS、出口地区（对照 Anthropic 官方名单）、api.anthropic.com、claude.ai、代理 / VPN、时区、时钟、官方状态页和账号使用地区，要等几秒钟。只提醒，不拦任何操作。

      账号信息

      添加账号

      Claude Code 账号需要在电脑上登录后导入，这样切换时才拿得到完整凭据：

      1. 在终端运行 claude，输入 /login 登录要添加的账号
      2. 回到这里点“导入当前登录”，或在终端运行 cam import --label 名字

      当前账号的凭据会在导入前自动保存，不会丢。
