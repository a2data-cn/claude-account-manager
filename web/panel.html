      隐私与数据源

      环境检测只发送电脑的出口 IP，不发送任何账号、邮箱或凭据。

      软件更新

      只在点“检查更新”时联网看一眼代码仓库，不会自动更新。更新只做快进，更新后自检没过会自动退回原来的版本；账号数据不受影响。桌面版是单独的安装包，不跟着更新。

      状态和颜色说明

      菜单栏图标（macOS）

      • 绿：空闲，一切正常
      • 橙：有 claude 会话在跑（信号格一格格涨）、额度快满、等你确认切换（一闪一闪）
      • 红：要处理——登录失效、额度用完、后台出错
      • 文字是当前账号和 5 小时额度已用的百分比，70% 起变橙、90% 起变红；点开菜单第一行写具体情况
      • 样式在菜单底部“图标样式”里选：四格信号或竖的红绿灯，颜色含义一样

      额度环和进度条

      • 画的是已用比例：70% 以下绿、70–89% 橙、90% 以上红；切到“剩余”显示时数字反过来，颜色不变
      • 5 小时和 7 天是 Anthropic 的两个额度窗口，到时间自动重置；按模型的周额度接口给了才显示

      账号状态标签

      • 正在用：Claude Code 当前登录的号
      • 注意（黄）：用量暂时拿不到、订阅已过期、登录过期了后台没替它续
      • 异常（红）：登录失效、凭据属于别的号、sessionKey 或 API Key 无效；点进详情看怎么办

      环境评分

      • 100 分起扣：出口不在支持名单、机房或代理 IP、代理 / VPN、时区语言和出口不一致、出口变化、同一账号多地区等各扣一些
      • 90 以上低风险，70–89 有风险，70 以下高风险；只提醒，不拦任何操作

      账号信息

      添加账号

      Claude Code 账号需要在电脑上登录后导入，这样切换时才拿得到完整凭据：

      1. 在终端运行 claude，输入 /login 登录要添加的账号
      2. 回到这里点“导入当前登录”，或在终端运行 cam import --label 名字

      当前账号的凭据会在导入前自动保存，不会丢。

      只用 Claude 客户端时，每个账号首次登录一次即可；读取本地额度无需登录 Code 或网页版。每个账号使用独立的本机配置，会话过期后可能需要重新登录。切换和重新打开都会退出并重启电脑上的 Claude 桌面版，请先处理好其中正在运行的任务。打开 Claude 的“设置 → 用量”后可读取额度缓存更新；Claude Code 命令行账号单独切换。
