    账号信息

    添加账号

    Claude Code 账号需要在电脑上登录后导入，这样切换时才拿得到完整凭据：

    1. 在终端运行 claude，输入 /login 登录要添加的账号
    2. 回到这里点“导入当前登录”，或在终端运行 cam import --label 名字

    当前账号的凭据会在导入前自动保存，不会丢。

    只用 Claude 客户端时，每个账号首次登录一次即可；读取本地额度无需登录 Code 或网页版。每个账号使用独立的本机配置，会话过期后可能需要重新登录。切换和重新打开都会退出并重启电脑上的 Claude 桌面版，请先处理好其中正在运行的任务。打开 Claude 的“设置 → 用量”后可读取额度缓存更新；Claude Code 命令行账号单独切换。
